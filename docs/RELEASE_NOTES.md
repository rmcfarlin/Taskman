# Taskman 2.4.2

Taskman is now distributed under the MIT License, with contribution guidelines and a private security-reporting route.

- Every release format includes the MIT license. Python packages also declare MIT in their metadata.
- The README links to the license, contribution guide, and security policy.
- The contribution guide covers development setup, tests, bug reports, and pull requests.
- The security policy covers the latest stable release and directs vulnerability reports to GitHub's private reporting form.
- Release smoke checks select the current version and platform and verify license and documentation contents before testing the installed app.

This release does not change task editing, Markdown storage, or keyboard workflows. Existing vaults and settings need no migration.
